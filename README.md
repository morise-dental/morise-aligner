# 森瀬歯科医院 マウスピース矯正 LP (morise-aligner)

福井県坂井市「森瀬歯科医院」のマウスピース矯正・小児矯正（プレオルソ）集客用ランディングページです。

## 概要
- **医院名**: 医療法人みらいえ 森瀬歯科医院
- **所在地**: 福井県坂井市坂井町下兵庫51-10-11（下兵庫こうふく駅徒歩10分・駐車場あり）
- **対象**: 成人マウスピース矯正、小児矯正（プレオルソ）
- **特徴**: 相談・検査・診断0円、3年間枚数制限なし保証、口腔内3Dスキャナー導入

## 構成ファイル
- `index.html` : LP本体マークアップ（全26セクション、スマホ常時最下部固定CTA、PCプレミアムヘッダー、Googleマップ埋め込み対応）
- `style.css` : レスポンシブCSS（モバイルファースト、PC最適化、シマー光彩エフェクト、アニメーション）
- `script.js` : インタラクション（スクロールリビール、カウントアップ、ライトボックス、CTAイベント）
- `image/` : 軽量・高画質WebP画像素材一式

## 主な機能・対応
- **完全レスポンシブ**: スマートフォン / タブレット / PC
- **常時下部固定ドック**: スマホ閲覧時に「LINEで相談」「Webで無料相談」を常時最下部に固定表示
- **リアルな患者さまの声**: 星評価（★★★★★ 5.0）・属性タグ付きの自然な口コミ掲載
- **近隣比較表**: S歯科医院・T歯科医院との透明性ある比較表
- **Googleマップ埋め込み**: アクセスセクションにインタラクティブマップを埋め込み
- **高速表示**: 全画像を軽量WebP化、遅延読み込み（loading="lazy"）対応
